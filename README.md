# Лабораторная работа №3. Вариант 11

Применить K раз медианный фильтр к матрице целых чисел.
Размер окна задаёт пользователь; выход за границы обрабатывается повторением
крайних элементов. Обработка выполняется несколькими потоками.

Сборка и запуск из папки `lab_03`:

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug
cmake --build build
cd build
./median_filter < ../data/input_10x10.txt > ../data/out.txt
```
